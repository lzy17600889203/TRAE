# 安全态势看板 PRD

## 1. Product Overview
面向公司安全运营团队(SOC)的可视化大屏看板,将实时攻击流、告警与安全评分三个维度聚合到单一视图。

- 核心问题:面对海量日志与告警,值班人员缺乏一张"一眼看懂"的全局态势图
- 目标用户:安全运营工程师、网络管理员、SOC值班人员
- 市场价值:提升MTTD(平均检出时间)与MTTR(平均响应时间)

## 2. Core Features

### 2.2 Feature Module
1. 中央全球攻击地图:ECharts world map + lines,实时展示攻击源到目标连线
2. DDoS攻击特效:连线变红加粗 + 目标节点"爆炸"粒子动画 + 顶部提示条
3. 左侧实时告警列表:按时间倒序滚动,高危告警红色标签 + "立即处理"按钮
4. 右侧安全评分雷达图:展示防火墙/入侵检测/漏洞修复/数据保护/身份认证五维度评分
5. 顶部状态条:实时CPU/带宽/攻击数三项指标

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 看板首页 | 全球攻击地图 | ECharts Map + Lines + effect scatter,支持DDoS事件触发视觉强化 |
| 看板首页 | DDoS状态面板 | 顶部红色横幅"检测到DDoS攻击,流量峰值10Gbps",地图连线加粗变红,目标节点爆炸 |
| 看板首页 | 实时告警列表 | Element Plus卡片式列表,高危告警红色tag,支持"立即处理"按钮 |

## 3. Core Process
`mermaid
flowchart LR
    A[定时事件流注入] --> B{是否为DDoS?}
    B -->|是| C[地图连线加粗变红 + 目标爆炸 + 顶部横幅]
    B -->|否| D[普通蓝色连线流入]
    E[定时告警注入] --> F{级别 == 高危?}
    F -->|是| G[红色标签 + 立即处理按钮]
    F -->|否| H[黄色/蓝色标签]
    I[定时评分更新] --> J[雷达图重绘 + 低分项提示]
`

## 4. User Interface Design

### 4.1 Design Style
- 主色:深蓝 #0a1931(背景),营造夜间指挥中心氛围
- 辅助色:青色 #00d4ff(普通连线)、红色 #ff3b3b(DDoS/高危告警)、橙色 #ffb347(中危告警)
- 按钮风格:扁平圆角,高危按钮采用红色实色并有脉冲动画
- 字体:Orbitron作为数字展示字体,"Microsoft YaHei"作为中文正文字体
- 布局:三栏大屏布局,中间地图占比约60%,两侧各20%
- 图标:lucide-vue-next图标组件,告警使用警示三角/盾牌图标
- 装饰:背景叠加细微网格纹理与径向光晕

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 看板首页 | 顶部状态条 | 3个指标卡(CPU/带宽/攻击总数),右侧时间 + DDoS告警横幅 |
| 看板首页 | 中央地图 | 深色世界地图底 + 青色飞行弧线 + 节点散点 + DDoS爆炸粒子 |
| 看板首页 | 左栏告警列表 | 卡片列表,内部滚动,高危项带红色tag与脉冲边框 |
| 看板首页 | 右栏雷达图 | 六边形雷达 + 图例评分,hover显示建议 |

### 4.3 Responsiveness
- 桌面优先(1920x1080 / 2560x1440大屏),最小支持1280x720
- 各模块采用flex + 固定比例(20% / 60% / 20%),窗口缩放时通过ECharts resize自适应

## 5. 预设交互与动效清单
1. DDoS攻击状态:地图连线变粗壮红色,目标节点爆炸(canvas粒子向外扩散),顶部红色横幅提示
2. 高危告警状态:左侧列表顶部出现红色标签告警,带"立即处理"按钮
3. 安全评分状态:雷达图低分项在tooltip中显示评分与建议
