# SAT 求解器可视化系统 - 产品需求文档

## 1. 项目概述

### 项目名称
**SAT 求解器可视化系统** (SAT Solver Visualizer)

### 项目类型
交互式 SAT 问题求解与算法可视化教学工具

### 核心功能摘要
基于 Vue 3 + Fastify + SQLite 技术栈实现的 CNF 公式 SAT 问题求解器，采用 CDCL 算法，提供完整的决策树生长动画、子句满足/冲突可视化、以及多种边界情况的异常展示。

### 目标用户
- 计算机科学学生与研究人员
- 算法学习者和教育工作者
- SAT 求解器开发者

## 2. 功能需求详述

### 2.1 CNF 公式输入

#### 2.1.1 手动输入模式
- 用户界面允许逐行输入子句
- 每行一个子句，格式：`x1 OR -x2 OR x3` 或使用空格分隔
- 支持否定符号：`-`、`!`、`~` 均可表示否定
- 实时语法校验与错误提示

#### 2.1.2 DIMACS 格式导入
- 支持标准 DIMACS CNF 格式（.cnf 文件）
- 粘贴框直接输入 DIMACS 文本
- 自动解析变量数量、子句数量与子句内容
- 支持文件拖拽上传

### 2.2 SAT 求解算法

#### 2.2.1 CDCL 算法核心
- **冲突驱动子句学习 (Conflict-Driven Clause Learning)**
- 实现以下关键组件：
  - 决策：选择未赋值变量
  - 单元传播：强制赋值
  - 冲突检测与记录
  - 冲突分析：生成学习子句
  - 回溯：非线性回跳到决策层级
  - 重启机制：周期性地重置搜索
  - 变量决策启发式：VSIDS (Variable State Independent Decaying Sum)

#### 2.2.2 算法控制
- 单步执行模式
- 连续执行模式
- 执行速度调节（慢速/中速/快速）
- 暂停/继续功能
- 最大决策步数限制

### 2.3 SQLite 数据存储

#### 2.3.1 子句数据库
- 存储所有原始子句
- 存储学习子句及其来源冲突
- 子句活跃度统计

#### 2.3.2 决策层级日志
- 记录每个决策点
- 记录传播过程
- 记录回溯历史
- 支持搜索历史回放

### 2.4 预设场景按钮

#### 场景一：不可满足矛盾子句场景
- 经典自相矛盾实例：`(x1 OR x2) AND (-x1 OR x2) AND (x1 OR -x2) AND (-x1 OR -x2)`
- 预期结果：快速证明 UNSAT
- 动画重点：冲突检测与立即回溯

#### 场景二：大规模变量组合爆炸场景
- 20+ 变量，指数级搜索空间
- 预期结果：明显观察到超时
- 动画重点：决策树快速扩张，搜索进度条

#### 场景三：单元传播链式反应场景
- 包含长链单元传播的实例
- 预期结果：展示传播效率
- 动画重点：链式传播动画效果

#### 场景四：纯文字消除简化场景
- 包含大量纯文字的实例
- 预期结果：展示简化效果
- 动画重点：纯文字消失动画

### 2.5 可视化与动画

#### 2.5.1 决策树生长动画
- 树形结构展示决策过程
- 节点表示决策层级
- 绿色分支表示满足路径
- 红色分支表示冲突路径
- 分支延伸动画（从父节点向外扩展）

#### 2.5.2 子句满足动画
- 当子句所有文字满足时显示绿色勾选
- 脉冲动画效果
- 满足时轻微抖动庆祝

#### 2.5.3 冲突回溯动画
- 冲突发生红色闪烁
- 回溯时路径擦除动画
- 冲突子句高亮显示
- 回溯计数器递增

#### 2.5.4 变量赋值动画
- 开关切换动画
- 真值状态颜色变化
- 赋值时轻微弹跳效果

#### 2.5.5 学习子句生成动画
- 新子句动态从冲突点浮现
- 渐入动画效果
- 子句库中新增条目闪烁

### 2.6 异常与边界情况可视化

#### 2.6.1 求解超时
- 进度条显示预估时间
- 超时警告（黄色闪烁）
- 超时后停止并提示用户
- 展示已探索的搜索空间比例

#### 2.6.2 无限回溯风险
- 回溯计数器实时显示
- 回溯深度指示器
- 检测到异常模式时红色警告
- 提供终止搜索选项

#### 2.6.3 内存占用
- 内存使用量实时显示
- 学习子句数量统计
- 内存警告阈值（80%时黄色，90%时红色）
- 提供清理学习子句选项

## 3. 技术需求

### 3.1 前端技术栈
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **状态管理**: Pinia
- **可视化**: SVG + Canvas 混合
- **动画**: CSS Animations + requestAnimationFrame
- **样式**: SCSS

### 3.2 后端技术栈
- **框架**: Fastify
- **数据库**: SQLite (better-sqlite3)
- **算法**: CDCL 实现

### 3.3 项目结构
```
sat-solver/
├── client/                 # Vue 3 前端
│   ├── src/
│   │   ├── components/    # Vue 组件
│   │   ├── stores/        # Pinia stores
│   │   ├── utils/         # 工具函数
│   │   └── styles/        # 样式文件
│   └── package.json
├── server/                 # Fastify 后端
│   ├── src/
│   │   ├── routes/       # API 路由
│   │   ├── solvers/       # SAT 求解算法
│   │   └── db/            # 数据库模块
│   └── package.json
└── package.json           # 根目录 workspace
```

## 4. 用户界面设计

### 4.1 布局结构
```
┌─────────────────────────────────────────────────────────────┐
│  顶部导航栏 (标题 + 预设场景按钮组)                          │
├───────────────────────┬─────────────────────────────────────┤
│                       │                                     │
│   公式输入区域        │      决策树可视化区域               │
│   (40% 宽度)          │      (60% 宽度)                     │
│                       │                                     │
│   - 手动输入框        │      - 树形图                      │
│   - DIMACS 导入       │      - 节点动画                    │
│   - 开始/控制按钮     │                                     │
│                       │                                     │
├───────────────────────┼─────────────────────────────────────┤
│   变量状态面板        │      求解统计与日志                 │
│   (真值指派显示)      │      - 步数/回溯/内存               │
│                       │      - 搜索历史                    │
└───────────────────────┴─────────────────────────────────────┘
```

### 4.2 色彩方案
- **主色调**: 深蓝 `#1a1a2e`
- **强调色**: 青蓝 `#0f3460`
- **满足色**: 翠绿 `#00d9a0`
- **冲突色**: 警示红 `#ff4757`
- **中性文字**: 浅灰 `#e8e8e8`
- **背景色**: 深空灰 `#0d0d1a`

### 4.3 动画时长基准
- 决策分支延伸: 300ms ease-out
- 子句满足动画: 200ms
- 冲突闪烁: 150ms × 3次
- 回溯擦除: 400ms ease-in-out
- 赋值切换: 250ms cubic-bezier(0.68, -0.55, 0.265, 1.55)

## 6. 非功能性需求

### 6.1 性能要求
- 决策树渲染 1000+ 节点时保持 30fps
- 算法执行时 UI 响应时间 < 100ms
- 数据库查询时间 < 50ms

### 6.2 兼容性
- 现代浏览器 (Chrome, Firefox, Edge, Safari 最新版)
- 桌面端优先（不支持移动端）

### 6.3 可访问性
- 键盘可完全操作
- 色彩对比度符合 WCAG AA 标准
